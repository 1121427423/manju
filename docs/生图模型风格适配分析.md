# 生图库全量风格适配分析

## 结论先行

这不是只有一种固定画风的模型样本；从当前库来看，生图能力覆盖**写实摄影、国漫/日漫、国风水墨、平面设计、中文标题和图示信息**等多个方向。最稳妥的定位是：**按提示词切换风格的通用视觉创作模型/模型族**，能够生成构图完整、风格明确的成品草案；人物身份一致、精确品牌/长文本和复杂图表仍需要参考图或后期校正。

## 全量范围

本次按 `library/` 全目录核对，而非只看最近加入的商品静物子目录：

- **1,014 张图像**、**178 个题材**、**13 个类别**，图像数据约 **3.15 GB**。
- 每类联络表在 `library/_contact/`；清单和评级见 `library/INDEX.json`、`library/README.md`。
- 库内标注的筛选结果为 **815 张 D**（可直接用）、**176 张 P**（结构可用，常需补字/裁切）、**23 张 I**（需 i2i 参考图维持角色一致）。这些是库内筛选标签，不等同于独立盲测分数。
- README 将来源记为 `agnes-image-*-flash` 探针图精选；它是精选数据集，且命名含多个 Rxx 测试批次。不能把这 1,014 张当成随机原始输出，也不能仅凭图片判定某个唯一模型版本。

## 按风格看，最适合做什么

1. **商业写实视觉**：商品静物、美食、建筑、风光、纪实场景。常见输出是柔光棚拍、真实质感、明确主体和干净背景，适合电商草图、广告情绪图、菜单/图库配图。
2. **风格化插画与场景**：日系动画场景、国漫角色、游戏概念。能在霓虹雨夜、绘本、动画背景、国漫角色概念之间切换；角色跨图一致性不如单张画面稳定。
3. **传统东方视觉**：水墨国风、书法标题、印章、纹样、浮世绘。适合国风包装、文化海报、装饰图案和短标题。
4. **图形与信息视觉**：平面设计、海报封面、中文排版、图示信息图。适合先产版式/视觉方向，再把正式文字、数据、logo 和细节用设计软件校准。

## 主要风险

- **人物身份连续性**：国漫角色类有 23/96 被标成 I（需要参考图），说明仅靠文字难稳定复用同一角色；做漫画、分镜或角色系列要绑定参考图。
- **精确文字/数据**：平面设计、海报和信息图中有较多 P 标签。模型能构造“像设计稿”的布局，但真实文字、数字、图表对应关系要逐项核查。
- **精确商品复刻**：商品图的摄影质感不等于几何/品牌准确。产品外形、接口、刻度、logo、标签和多角度一致性要用实物图作参考并后期修。
- **精选偏差**：`library/README.md` 说明这批是探针图按评级筛选、每题材取细节分较高者；因此它更能说明“模型能达到的上限样例”，不能代表所有提示词和随机种子的平均表现。

## 实用选择建议

- **优先用它**：风格明确的单张主视觉、商品/美食棚拍草案、环境概念图、国风水墨、动画背景、短标题视觉、图标/海报版式初稿。
- **配合参考图**：角色系列、精确产品、同一场景多视角、需要跨图保持设计的内容。
- **后期制作**：长文案、logo、表盘/包装小字、图表数据、工程尺寸、印刷规范。

## 一句话定位

**风格跨度大、构图和氛围能力广的通用生图工具；最强在“单张画面做得像一张完成的视觉稿”，需要谨慎的部分是“跨图保持同一对象”和“精确文字/数据/商品结构”。**
