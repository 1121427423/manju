# 生图模型风格适配分析（商品静物样本）

## 样本范围与结论

依据 GitHub 分支中 `library/04-商品静物/` 的 **43 张 PNG**，覆盖 13 类商品/材质题材；共 36 张 2048×2048、4 张 2496×1664、3 张 2624×1472。除陶瓷花瓶只有 1 张外，其他题材包含多张变体，可观察构图和造型波动。

**结论：这批图最明显地体现出“干净、写实的商业棚拍 / 商品静物摄影”能力，适合白底电商主图、产品概念图、材质微距和广告情绪图；不宜未经校对就用于精确 SKU 复刻、品牌/规格展示或同一产品的多角度一致图组。**这里评价的是这批生成结果呈现出的适配性，不代表已完整测试模型所有风格，也无法仅凭像素确定模型型号或训练来源。

## 观察到的视觉风格

- **光线与背景**：高键、柔和的大面积棚灯，白/浅灰无缝背景，阴影轻且接地；少量黑底微距作为高反差特例。
- **质感表现**：玻璃、陶瓷、抛光金属、编织布、刺绣等表面细节有较强的摄影感；常见产品轮廓清楚，细节锐利。
- **镜头语言**：大量居中单品、三分之四角度和极近景微距，浅景深明显；整体偏“电商目录图 + 高端品牌广告静物”，不是插画、动漫或电影奇幻风格。
- **色彩**：低饱和中性色为主，产品本色承担视觉重点；画面干净克制，适合后续排版与背景替换。

## 按任务的适配度（样本目测，10 分制）

| 用途 | 适配度 | 样本表现与边界 |
|---|---:|---|
| 白底/浅灰底单品主图、目录图 | **8/10** | 笔电、耳机、鞋、瓶罐都能形成干净棚拍观感；但须检查主体大小、边缘裁切和角度是否合要求。 |
| 无品牌商品概念图、外观提案 | **8/10** | 适合快速探索材质、颜色、轮廓和布光；多张输出会改变视角或局部设计，不可直接当作同一 SKU 的准确复刻。 |
| 材质微距、纹理特写 | **8.5/10** | 丝织/刺绣、玉石、金属和表面肌理有说服力；微距也容易把装饰、纹理或结构“编造”得过多。 |
| 高端静物广告氛围图 | **8/10** | 光线与质感表现好，适合没有严格文案/规格要求的品牌视觉草案。 |
| 同一商品多视角、严格产品一致性 | **5/10** | v1/v2/v3 之间常改变机位、轮廓、配件和细节；单靠文字很难锁定商品几何。 |
| 品牌字样、表盘刻度、标签/包装文案 | **3/10** | 手表表盘/刻字出现不可读或虚构文字风险；正式品牌资产、数字、规格不能直接信任。 |
| 大留白、极小主体的极简构图 | **5/10** | 瓶子样本有主体偏低偏小、留白过多的情况；需要明说主体占画幅比例及摆放位置。 |

## 各题材的具体观察

- **比较适合**：陶瓷花瓶、锤纹金属锅、装饰茶罐、丝织/刺绣与玉石微距——光泽、表面质感和柔光棚拍有较好的商业静物感。
- **可做概念但须验形**：耳机、笔电、鞋、制服。三版常更换角度、裁切或局部构造；鞋的变体中能看到额外/重复视角或边缘裁切，制服的口袋、色块等也会变化。
- **需要人工校对**：手表宏观图的品牌字样、刻度和机芯细节不可靠；音箱样本偏局部网布特写，不一定能给出完整商品外观。
- **极简透明瓶与皂块**：背景和光感干净，但瓶身对比偏低、主体有时占画面太少；用作构图/光线草图比直接当最终电商图稳妥。

## 推荐使用方式

1. **概念探索/风格板**：一次生成多版，挑构图与材质方向；再人工统一商品轮廓、颜色、配件和镜头角度。
2. **准确商品图**：上传真实商品照作图像参考或走局部编辑；明确“保持外形、比例、接口、缝线、数量、颜色与标识不变”，不要仅靠文字生成真实 SKU。
3. **提示词建议**：指定“commercial studio product photography, one complete product, centered, entire object visible, occupies 65–75% of the frame, three-quarter front view, seamless light-gray background, soft diffused key light, subtle contact shadow, realistic material, no extra objects”。
4. **负面约束**：`cropped product, duplicate product, extra parts, changed geometry, invented logo, illegible text, wrong labels, floating object, excessive empty space`；若要品牌字样，建议后期排版，不让模型绘制。
5. **微距纹理**：明确“macro detail of [material], crop only the intended surface, controlled shallow depth of field, preserve pattern scale”；需要重复纹样时额外要求规则和连续性。

## 一句话定位

**把它当成“商品摄影美术指导/概念图生成器”很好用；把它当成“精确产品建模、品牌排版或多视角一致性工具”则风险较高。**
