# 01 · 制作圣经（Production Bible）

**片名**：《青冥 · 伞》— 40 秒先导 PV（漫剧 / 3D 写实风）
**一句话**：雨夜石阵，白衣剑修照雪斩向罗盘伞下微笑的玄罗，一剑劈开的不是敌人，而是她身后的天。
**类型**：玄幻 / 打斗 / 悬疑钩子（"漫剧"式追更片）
**时长**：40.0 s ｜ 画幅 16:9（同时出 9:16 竖版安全区）｜ 帧率 30 fps

---

## 一、创作思路（为什么这么设计）

参考片（39s）之所以"高级"，不是特效多，而是**克制**：

1. **只讲一件事**：两个女人的第一次交手。没有设定讲解、没有旁白，全靠画面。
2. **色彩单一化**：全片青绿 + 古金，观众 3 秒就能记住"这部片子的颜色"。
3. **节奏三段式**：长镜养气氛（0–16s）→ 0.5 秒爆切（16–27s）→ 巨物反转型收尾（27–40s）。
4. **结尾必须是"更大的东西"**：主角打完，真正的敌人（巨手/魔神）才露 2 秒 —— 这就是漫剧的追更钩子。

我的复刻策略：**继承结构，替换符号**。结构公式照抄（节奏、景别、色彩、四件套打击感），但角色、道具、片名全部原创，避免版权问题。

**我加的"作者印记"**：把参考片的"罗盘伞"升级为"**能开成盾、能转成阵、伞面是卦象的青铜罗盘伞**"，一个道具承担三种叙事功能（压迫感 / 防御 / 施法），这样 40 秒里只用一个道具就能撑起全部打斗逻辑。

| 眼 | **青绿竖瞳**（非人特征），睫毛长，眼尾上挑，下眼睑有细小咒纹 |
| 肤 | 冷白，微透，近景可见皮下次表面血色 |
| 定妆图 | `assets/keyart/CHAR_xuanluo.jpg`（以此为准） |
| 服 | 墨绿 / 青黑 交领长裙，衣料半透如烟，下摆破碎成雾；肩部有青铜甲片；手腕缠绕金铃串；赤足 |
| 道具 | **九幽罗盘伞**：直径 1.2 m 青铜伞，伞骨 12 根，伞面刻卦象与裂纹，边缘垂 8 只金铃与金穗。可旋转、可张开成盾、可悬空成阵 |

## 三、场景设定：天枢石阵

> 概念图：`assets/keyart/SCENE_altar.jpg`（八角祭坛 + 卦象地纹 + 远塔 + 悬浮碎石 + 青绿雾）
> **所有镜头图都以这三张图为视觉参考**，这是保证角色/场景一致性的唯一手段。

| 层 | 内容 |
|---|---|
| 前景 | 断裂石柱（距镜头 1–3 m）、积水、雨丝、绿雾贴地流动、浮空碎石 |
| 中景 | 八角祭坛平台，地砖刻卦象，缝隙渗出青光；中央有直径 6 m 的圆形阵纹 |
| 远景 | 一座 5 层**高塔**剪影（塔顶有旋转环），乌云翻滚，闪电从云隙落下 |
| 天空 | 深墨蓝 `#0C1620`，云层有内部青绿透光（"天在发光"的暗示） |
| 地面 | 湿石，粗糙度低，强镜面反射；水洼深度 2 cm，可溅起 |
| 天气 | 中雨，雨丝 15° 斜向；地面有白色雨雾 |
| 光源 | ① 主光：云隙冷月光（顶侧逆光 `#9FC6D8`）② 辅光：绿雾自发光 `#5FE3C0` ③ 点缀：金铃、剑芒 `#FFE7A8` ④ 爆点：白闪 2–4 帧 |

> 场景设计原则：**永远让观众看得见"三层"**。近景有石块，中景有人，远景有塔 —— 一眼判断空间。

## 四、画面风格规范（复刻参考片的"质感公式"）

| 维度 | 规范 |
|---|---|
| 色彩 | 主色青绿（`#1F6B5E`/`#5FE3C0`）占 60%，暗蓝 `#0C1620` 占 30%，古金 `#C9A24B` 占 7%，纯白 3% |
| 对比 | 低调，暗部保留细节不纯黑（最低 18/255）；高光允许过曝 |
| 镜头 | 24–35 mm 等效为主（近景 50 mm，特写 85 mm 微距感）；有轻微球面畸变与暗角 |
| 景深 | 极浅（f/1.4 观感）；近景只有眼睛/伞骨在焦内 |
| 颗粒 | ISO 800 观感，颗粒强度 0.02–0.04 |
| 特效风格 | 体积感优先（雾、光、水），不用"卡通描边"；能量用**亮芯 + 柔边 + 拖尾**三层 |
| 特写 | 每 8 秒至少一次**眼睛或手**的极特写，建立"皮肤级"真实感 |
| 构图 | 大量对称与中心构图；巨物出现时用**仰视 + 下压画幅** |

### 打击感四件套（每一击必须齐）
1. **光**：撞击点冲光 + 全局亮度跳 20–40%
2. **粒子**：火花 / 水花 / 碎石，反向喷出
3. **镜头**：3–6 px 随机抖动 + 1–2 帧冲击变焦（punch-in 4%）
4. **声音**：金属尖啸 + 低频撞击（80 Hz）+ 短混响
