## 1. 角色一致性操作规范

1. 先只跑一张玄罗 / 一张照雪的定妆三视图（`assets/keyart/`），**挑最满意的那张定稿**，之后不再改。

2. 每条镜头提示词都上传定稿图作为 image reference（权重 0.45–0.6）。

3. 同一角色所有镜头使用**同一个 seed**，只改镜头/动作/光线描述。

4. 出现脸崩时，先用局部重绘（inpaint）只修脸，不要重跑整张。

5. 全片两个角色**不能同框超过 3 个镜头**（远全景），否则一致性风险最高。

## 3. 图生视频参数建议

| 参数 | 建议值 | 说明 |
|---|---|---|
| 时长 | 1.2–3.0 s/镜 | 与 `shots.json` 的 `dur` 一致；超出就分段生成再剪 |
| 运动强度 | 0.4–0.6 | 打斗镜头 0.7；特写 0.25（避免脸部形变） |
| 镜头运动 | 与 `motion` 段一致 | 推 / 拉 / 摇 / 跟，尽量单一运动，避免「边推边转」 |
| 帧率 | 生成 24fps → 交付 30fps | 用光流补帧，避免卡顿 |
| 分辨率 | 1080p 生成 → 4K 放大 | 放大后再做胶片颗粒与暗角 |
| 首尾帧 | 关键帧作为首帧 | 需要定格的一击，把同一张图作为尾帧（freeze） |


## 4. 与后期管线的接法

生成好的镜头片段直接替换 `assets/shots/` 下的对应素材即可：

1. 把生成的视频按镜头切成 `assets/video_in/A01_feet.mp4` …（可选）
2. 若走「AI 视频」路线：`render/render_video.py` 改用视频输入，只做调色 + 特效叠加 + 剪辑
3. 若走「静帧 + 2.5D」路线（本仓库默认，零成本可跑）：用 `assets/shots/*.jpg` 直接渲染
4. 两条路线的**剪辑点、调色、音轨完全共用**，所以前期拆解和声音设计的钱不会白花
