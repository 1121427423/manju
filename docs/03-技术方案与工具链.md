# 03 · 技术方案与工具链

## 一、总体思路：把「AI 生成」和「确定性渲染」拆开用

很多人做 AI 短片的失败模式是：**全都丢给视频大模型**，结果镜头发飘、角色变形、节奏失控、音画不同步。

本项目的思路是**三层分工**：

```
第 1 层  逆向工程   参考片 → 量化数据（切点/节奏/色板/响度）→ 可执行的规范
第 2 层  视觉资产   AI 图像模型 → 定妆图 + 22 张关键帧（一致性靠参考图锚定）
第 3 层  动态化     自己的渲染引擎 → 运镜/特效/剪辑/调色/声音（100% 可控、可重跑）
```

- **该由 AI 做的**：皮肤、布料、金属、光学的"真实感"——这恰恰是程序化最难的一面。
- **该由代码做的**：节奏、镜头运动、剪辑点、特效时序、声音——这恰恰是 AI 最不可控的一面。
- 两者相乘，才能得到"看起来像 3D 动画成片、但成本接近零"的结果。

## 四、渲染引擎做了什么

### 4.1 运镜（2.5D）
- 关键帧按 16:9 原生裁切成"画布"，`affine()` 以中心为锚做 **缩放 + 旋转 + 平移**，输出 1280×720。
- 每个镜头由 `shots.json` 的 `zoom:[z0,z1]`、`pan`、`rot`、`shake`、`ease` 驱动，逐帧插值。
- 抖动 = 两层不同频率正弦 + 指数衰减冲击项 + 微小 roll，模拟手持与撞击。

### 4.2 VFX 层（8 类，全部程序化）
| 特效 | 实现要点 |
|---|---|
| 雨 | 三层不同速度/长度/虚化的粒子线，逐帧积分 + 风偏 |
| 体积雾 | 可平铺分形噪声 + 双层滚动 + 贴地权重 |
| 卷动光柱 | 高斯横向分布 × 多正弦闪烁 |
| 火花 | 欧拉积分 + 重力 + 阻尼 + 逐帧拖线 |
| 绿烬/尘埃 | 正弦漂浮粒子 + 大半径模糊 |
| 冰晶爆发 | 26 个多边形冰锥按距离延迟生长 + 边缘提亮 |
| 空间裂缝 | 噪声多边形遮罩 + 双层边缘发光 + 内部流动噪声 |
| 冲击/白闪 | 径向冲光 + 多角度星芒 + 全屏提亮，含降饱和 |
| 能量球 / 剑光 | 高斯核心 + 呼吸环 + 白芯加色 |
| 皮肤侵蚀 | 随机游走血管 + 双层模糊叠加 |

### 4.3 后期
- **Bloom**：三级降采样模糊叠加（近似高斯），带亮度阈值
- **调色**：阴影偏青 / 高光偏暖 / 对比 / 饱和 / 提黑（暗部不纯黑）
- **镜头畸变色散**：R/B 通道反向缩放 0.16%
- **暗角 + 顶部压暗 + 中心提亮**（视线引导）
- **胶片颗粒**：中间调更明显的亮度自适应噪声

### 4.4 字幕与片名
- 竖排小字逐字浮现（左下达芬奇式排布），带发光层。
- 片名卡：虚化场景 + 旋转金环（72 根刻度）+ 字距拉开的衬线大字 + 英文副标 + 收黑。

### 4.5 声音（`render/lib/audio.py`）
自研合成器，无采样库依赖：

| 音源 | 合成方式 |
|---|---|
| 雨 | 带通白噪 + 湿度层 + 320 个随机水滴正弦 |
| 风 | 低通噪声 × 慢 LFO |
| Drone | 41.2 Hz 基频多谐波 + 拍频，结尾叠加 28 Hz 轰鸣涌起 |
| 弦乐 Pad | 7 段 Dm–Bb–Gm–A 和弦，多失谐正弦 + 慢起音 |
| 金铃 | 5 个非谐波分音（1/2.76/5.4/8.93/13.3）+ 独立衰减 |
| 剑鸣 | 2.3 kHz 金属分音 + 高通瞬态 |
| 撞击 | 下坠低频 + 高通咔哒 + 中频噪声体 |
| 雷 | 低通噪声 × 双包络 + 高频炸裂 |
| 冰碎 | 90 个随机短正弦簇 + 44 Hz 余震 |
| 撕裂 | 18 Hz 振幅调制的中频噪声 + 33 Hz 次低频 |
| 心跳 / 耳鸣 | 双搏动包络 / 6.1 kHz 正弦 + 包络 |

混音：FFT 卷积混响（2.2 s 指数衰减 IR）→ 母线 tanh 软压缩 → 归一化到 **−1 dBFS**，
实测 **RMS ≈ −12.9 dBFS**，比参考片（−17.4 dB，流媒体压平）略激进，但听感更"电影"。

## 五、成本与性能

| 项目 | 本仓库（静帧 2.5D 路线） | AI 视频路线（参考片同水准） |
|---|---|---|
| 关键帧生成 | ≈ 25 次出图 | 同 |
| 视频生成 | **0** | 23 镜 × 2 次重试 ≈ 46 次调用，约 ¥150–600 |
| 渲染算力 | 2 核 CPU，514 帧 ≈ **4.5 分钟** | 云 GPU 数小时 |
| 后期/音效 | 0（程序化） | 素材库/外包约 ¥300–1500 |
| 人力 | 1 人 1 天 | 3–5 人 3 天 |
| **合计** | **≈ 0 元** | **≈ ¥500–2000 / 40 秒** |

## 六、已知差距（诚实清单）

| 参考片 | 本仓库 | 差距原因 |
|---|---|---|
| 真人级动态打斗、布料解算 | 静帧 + 2.5D 视差 | 无视频生成 API / GPU |
| 流体雾与水的真实解算 | 噪声近似 | 同上 |
| 角色微表情、说话 | 无 | 无口型/面部驱动 |
| 全身动作连戏 | 单帧推进 | 战斗段落需 i2v 才能"真打" |
| 皮肤次表面散射 | 关键帧自带 | 已由图像模型解决 |
| 4K 交付 | 720p/1080p | 沙箱算力 |

> 结论：**画面气质、节奏、分镜、声音已经对齐参考片标准；"真打"的动态只能交给视频大模型。**
> 本仓库的价值是把"贵且不可控"的部分压缩到最小：故事、镜头、节奏、色彩、声音全部可控可重跑，
> 视频模型只负责最后一步"让静帧动起来"。详见 `docs/02-分镜提示词包.md`。

## 七、复现步骤

```bash
pip install --break-system-packages numpy pillow imageio-ffmpeg fonttools
python3 scripts/analyze_ref.py original-720p.mp4   # 复现拆解数据
python3 scripts/prep_assets.py                     # 素材裁切 + 联络表
python3 -m render.render_video                     # 出片 → out/青冥·伞_40s.mp4
python3 -m render.lib.audio out/score.wav          # 单独出音轨
```
