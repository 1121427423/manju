| 项目 | 数值 |

## 2. 镜头节奏（切点 + 运动量）

场景硬切（scene 阈值 0.3）：`3.8 / 15.6 / 18.2 / 23.4 / 24.0 / 25.5 / 25.8 / 27.1 / 31.1 / 32.9 / 34.7 / 36.3 s`
逐帧差（10fps 采样）尖峰：`3.8 / 15.6 / 18.2 / 23.5 / 24.0 / 25.5 / 25.8 / 27.1 / 32.3 / 32.9 / 36.3 s`

**节奏结构（平均镜头长度 ASL）**

| 段落 | 时间 | 功能 | 剪辑特征 |
|---|---|---|---|
| ① 引子 | 0 – 6 s | 赤足踏水 → 绿雾缠足 → 伞下人物 | 慢，4–6s 长镜；只切 1 次 |
| ② 凝视 | 6 – 15.6 s | 伞、闪电、半脸、竖瞳 | 中速，2–3s；情绪压迫 |
| ③ 交手 | 15.6 – 27 s | 白衣剑修入场 → 对冲 → 火花 → 罗盘成盾 | **最快**，0.3–1.5s 快切，多段“瞬切 + 白闪” |
| ④ 大招 | 27 – 34 s | 冰晶爆发 / 绿光球 vs 剑 / 光爆 | 中速，1.6–2s，命中瞬间抽帧定格 |
| ⑤ 反转 | 34 – 39 s | 徒手撕裂缝 → 骷髅魔神 → 巨手撑地 | 突然放慢 + 黑场留白 |

实测：全片 13 个硬切 = **ASL ≈ 3.0s**，但分布极不均匀 —— 前 16 秒只有 1 个切点（长镜养气氛），交手段落 11 秒里有 9 个切点（0.3–1.5s）。
**这是“漫剧打斗”最核心的节奏公式：慢铺垫 + 极速爆切 + 定格收束。**

逐段运动量（帧间差均值，越大越“动”）：引子 10–11 → 凝视 26–29 → 交手 20–37 → 高潮 21–29 → 反转 13–17。
→ 全片**没有静止镜头**，最“静”的引子段也在持续微推 + 粒子浮动。

## 3. 调色与影调（逐帧统计）

- 全片平均亮度 **71.6 / 255**（低调布光，中位数比均值低，说明大量暗部 + 少量高光爆点）。
- 色偏指标（teal = G+B−2R；gold = R+G−2B）：全片 **teal = +63.4 / gold = −41.9**。
  → 极端的**青绿主色 + 冷蓝暗部**，金色只作为“点缀存在”（罗盘、金铃、铃穗）局部出现。
- 分段亮度曲线显示两个爆点：**20–26s（lum 115/120）** 与 **24s 白闪**，对应兵器对撞火花与光球爆闪。

**色板（从关键帧采样，HEX）**

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色·冥青 | `#1F6B5E` | 绿雾、咒力、罗盘光环 |
| 主色·荧光青 | `#5FE3C0` | 发光边缘、粒子、竖瞳 |
| 暗部·墨蓝 | `#0C1620` | 夜空、远景、暗部填充 |
| 过渡·石灰 | `#6E7A80` | 湿石地面、石柱、雨幕 |
| 中性·冷白 | `#E8F4F2` | 白衣、剑光心部、白闪 |
| 点缀·古金 | `#C9A24B` | 铜伞骨架、金铃、锁链、字 |

**关键影调手法（复刻必须保留）**
1. 大面积暗部 + 单点高光（人物永远比背景亮一档）。
2. 青绿**体积雾**贯穿全片，既是气氛也是“光的载体”。
3. 湿地面镜面反射，让人物与光效有二重投影。
4. 白闪/光爆时**整体降饱和 + 抬高光**，只有 2–4 帧。
5. 暗角 + 轻微镜头畸变 + 颗粒，制造“CG 感之外的胶片脏感”。

## 5. 声音设计（实测包络）

- 全片 **RMS 中位 −17.4 dB，峰值 −8.7 dB**，p10 −19.8 / p90 −12.8 → **动态压缩得很平**（流媒体响度统一），几乎无静音段。
- 显著起音（+6dB 以上跳变）只有 **0.0 / 8.6 / 23.3 / 24.3 / 35.7 / 36.4 s** → 音乐驱动，而非音效堆叠。
- 频谱质心 ~2.3–4.1 kHz（偏亮）→ 大量**雨声/风声/金属泛音/铃**在高频铺底。
- 推论的声音层结构：
  1. **底噪层**：雨 + 风 + 低频 drone（贯穿，不断）
  2. **音乐层**：弦乐/大鼓/人声吟唱，随剪辑点加鼓
  3. **音效层**：只在 23.3（兵器相撞）、24.3（盾展开）、35.7（裂缝撕开）、36.4（魔神登场）四个“重音”砸下去
  4. **留白**：结尾 37.5s 后骤降到只有低频轰鸣，为下一集留钩子

## 6. 复刻难度与结论

**能直接复刻的（本仓库已实现）**
- 节奏 / 分镜 / 时长 / 画幅 / 剪辑点 / 色板 / 影调
- 动态分镜（Previs）：镜头运动、白闪、抽帧定格、粒子、冲击波、雨、颗粒、字幕
- 声音设计（程序合成 drone / 雨 / 铃 / 剑鸣 / 撞击 / 轰鸣）
- 全套 AI 视频生成提示词（角色一致性 + 逐镜首尾帧）

**必须在外部大模型完成的（本沙箱无 GPU、无视频生成 API）**
- 角色级 3D/写实影像动态生成（参考片是 3D 动画/CG 级渲染）
- 流体解算、布料解算、次表面散射、体积光
→ 见 `docs/01-制作圣经.md` 的“成片生产链路”，以及 `prompts/` 下的可直接投喂的提示词包。

**参考片“标准”的本质不是画质分辨率，而是这 5 件事：**
1. 单一强色彩主题（青绿）+ 单一强点缀（古金）
2. 每个镜头都有明确的**前中后景三层**
3. 每一击都有**光 + 粒子 + 镜头抖 + 声音**四件套
4. 节奏：长铺垫 → 0.5s 爆切 → 定格
5. 结尾留悬念（裂缝/巨手/眼睛），这是“漫剧”留住观众的关键
