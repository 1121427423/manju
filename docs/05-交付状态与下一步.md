## 三、唯一未达标项与补法

**主体局部运动量 −64.2%**：参考片的运动来自**肢体动画 + 布料解算 + 流体解算**，本仓库只有
「静帧 + 2.5D 视差 + 粒子 + 手持微抖」。已做的补偿：运镜幅度 ×1.35、全镜头手持、
爆切段平均 1.2 秒一刀、每击四件套（光/粒子/镜头抖/声音）。

**真正补齐的路径**（沙箱无视频生成 API，故未做）：
把 `docs/02` 每条 `motion` 描述投给图生视频模型（可灵 / Vidu / Runway / Veo），
生成的片段替换 `assets/shots/*.jpg` 作为动态素材源，**剪辑点、调色、音轨完全复用**，
不需要重做任何前期工作。详见 `docs/09-连续运动方案.md`。

## 五、还可以继续做的四件事

1. **主体局部运动量（17.9 分，唯一的结构性短板）**：静帧 + 2.5D 的上限就在这里。
   补法只有两条 —— 图生视频替换素材（见 `docs/09`），或逐镜补中间关键帧（成本极高）。
2. **青绿 77.4 分**：实测 `cool` 的红光分量是主杠杆，但本轮搜索显示继续抬高会拖累金色与亮度，
   净收益接近零。若要做，应配合 `tint` 的蓝通道一起调，并把目标从"数值对齐"改成"分段：
   暗部更青、亮部更中性"。
3. **暗部 p5 82.7 分**：`black_lift` 0.045 → 0.058 实测可把抽样 p5 从 11.7 抬到 13.7，
   但基准点本身随 gamma 改动漂移过，需整片重渲才能确认净收益（约 12 分钟）。
4. **9:16 竖版**：社交平台主战场，需按主体重新构图并移动字幕安全区（约 1 小时）。
