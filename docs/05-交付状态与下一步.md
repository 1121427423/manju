## 三、唯一未达标项与补法

**主体局部运动量 −64.2%**：参考片的运动来自**肢体动画 + 布料解算 + 流体解算**，本仓库只有
「静帧 + 2.5D 视差 + 粒子 + 手持微抖」。已做的补偿：运镜幅度 ×1.35、全镜头手持、
爆切段平均 1.2 秒一刀、每击四件套（光/粒子/镜头抖/声音）。

**真正补齐的路径**（沙箱无视频生成 API，故未做）：
把 `docs/02` 每条 `motion` 描述投给图生视频模型（可灵 / Vidu / Runway / Veo），
生成的片段替换 `assets/shots/*.jpg` 作为动态素材源，**剪辑点、调色、音轨完全复用**，
不需要重做任何前期工作。详见 `docs/09-连续运动方案.md`。
