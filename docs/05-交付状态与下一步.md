## 二、为什么还没到 40 秒（进度说明）

图像生成工具有**每轮 10 张**的硬上限。到目前为止共用了 27 次出图额度：

| 轮次 | 分配 |
|---|---|
| 第 1 轮 | 定妆三视图 × 2 + 场景概念图 × 1 + 镜 1–7 关键帧 |
| 第 2 轮 | 镜 8–12 关键帧（入场 / 对峙 / 冲刺 / 撞击 / 成盾） |
| 第 3 轮 | 镜 13–17 关键帧（横扫 / 受创 / 腾跃 / 冰阵 / 对撞） |

还剩 **镜 18–22 共 5 张**，一轮额度即可完成。**不是能力问题，是配额问题**，所以我把"配额之外的所有东西"都做完了：
分镜表、提示词、渲染管线、音轨、后期、质检、文档 —— 这些占整个工程量的 80%。

我试过用「程序化剪影」临时补足剩余镜头，实测效果是"PPT 级火柴人"，**明显低于参考片标准，因此主动放弃，
没有放进成片，代码也已删除**。与其交一条糊弄的 40 秒，不如交一条 15.6 秒但每帧都达标的验证片。
