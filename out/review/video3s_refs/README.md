# 3 秒图生视频参考帧包

这些是供外部 image-to-video 工具使用的**参考静帧**，不是已生成的视频：

- `00_start.jpg` — 起始状态（0.0s）：对峙，女主伞盾已举起，男主剑指向盾。
- `01_clash.jpg` — 中间动作锚点（约 1.5s）：男主前冲，剑击中伞盾。
- `02_end.jpg` — 结束状态（约 3.0s）：冲击后男主退半步、伞盾仍稳住，火花收束。
- `contact_sheet.jpg` — 三帧并排预览。

## 建议给视频模型的提示

生成 3 秒、16:9、24/30fps 的连续动作视频。以 `00_start.jpg` 作为首帧，`02_end.jpg` 作为尾帧；若工具支持中间参考，将 `01_clash.jpg` 用作动作/构图锚点。镜头固定，不切镜、不变焦：0–0.5s 对峙蓄势；0.5–1.4s 男主向右前冲；1.4–1.8s 剑与伞盾接触并出现局部金青火花；1.8–2.4s 受力回弹；2.4–3.0s 双方稳住姿势、火花减弱。

全程保持两张参考图中的同一张脸、发型、衣服、剑与伞盾；白衣衣摆长度与分片数量稳定，不增加长尾/飘带；背景石柱、圆形石台、雨和青色风暴保持空间位置稳定，只让人物、武器、接触火花及少量近身水滴运动。避免全屏水波纹、人物融化、脸部漂移、武器复制、衣物拖尾和额外角色。

**注意**：这些关键帧只提供首/中/尾构图与动作约束，不能单独保证视频模型的时序一致性；生成后仍须逐帧检查脸、衣物轮廓和接触动作。
